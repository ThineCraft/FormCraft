The proposition

Built to remain understandable—and yours.

FormCraft is intended to let one form move between structured data, a fillable PDF, a browser, and printed paper—then return to ShareCraft as one traceable record.

Proposed scope

What FormCraft is intended to make possible.

01

Planned capability

PdfCraft in the browser

PdfCraft is intended to render fillable forms, offer a read-only view for completed records, and submit electronic responses to ShareCraft’s controlled public side.

02

Planned capability

A QR code for each instance

Each printed document can carry a QR code that acts as an alignment anchor and resolves an opaque instance identity, template version, field map, and ShareCraft record without exposing personal data.

03

Planned capability

A guided paper panorama

The PdfCraft phone app is intended to send a guided video stream while the user moves across the page, assemble it like a panorama, and progressively fill the electronic form from the captured marks.

04

Planned capability

Optional public attestation

A finalized document hash can be digitally signed and submitted to OpenTimestamps for a Bitcoin-anchored existence proof while the document itself remains private.
