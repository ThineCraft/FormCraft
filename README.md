# FormCraft

Website: [form.thinecraft.io](https://form.thinecraft.io)

FormCraft is the planned open-source forms and structured data-collection project in the ThineCraft family. Its direction includes PdfCraft fillable forms, ShareCraft submission flows, per-instance QR anchors, guided phone capture of printed forms, and optional Bitcoin timestamp attestation.

> **Status:** Placeholder repository. No working implementation is provided or implied.
